ADD YOUR IMAGES
1. Copy the company logo into assets/ and name it: logo.png
2. Copy the employee/team cleaning photo into assets/ and name it: cleaning-team.jpg
The pages include fallback stock photos until you add the real company photo. Replace those images with the supplied company photo for final publication.

WHATSAPP

PUBLISHING
Upload all HTML, CSS and JS files together, preserving the folder structure, to your web host's public website folder (often public_html).
